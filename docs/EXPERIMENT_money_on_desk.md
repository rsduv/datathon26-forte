# Эксперимент: модель «деньги на столе» (сб 17.10, вечер) — НЕ включена в сервис

**Зачем:** поймать X-4, X-38 (деньги прошлого клиента на столе при новом), X-26 (ушла — деньги на столе).

**Что сделали:** вырезка рабочего стола по рамкам предметов (`engine.table_box`) из кадров сервиса (1 fps) всех 40 роликов,
покадровая разметка «деньги лежат на столе: 0/1/?» (~1100 кадров), признаки OpenCLIP ViT-B-32 (MIT) локально,
логистическая регрессия; вариант 2 — 12 перекрывающихся кусочков стола + multiple-instance (максимум по кусочкам).
Проверка leave-one-video-out (ролик оценивается моделью, обученной без него).

**Результат:** весь стол — precision 0.40 / recall 0.41; по кусочкам — при 2 ложных кадрах ловит 14% кадров с деньгами.
X-4: 0 из 24 кадров с деньгами, X-26: 0 из 11, X-38: 4 из 33. Удостоверение и бумаги путаются с пачками.

**Вывод:** пачки слишком мелкие для CLIP на этом разрешении; включение сломало бы «0 ложных из 19».
Для X-4/X-38 перспективнее правило по поведению: между уходом клиента 1 и приходом клиента 2 кассир не вставал к сейфу (эталон X-5 — встаёт).
Также: для ракурсов, где детектор видит только счётную машинку (X-2, X-30–33, X-40, X-44, X-45), `table_box` даёт узкую рамку — не весь стол.

# Ночь 17→18.10: что сработало и что честно отброшено (OWLv2 + детектор, GPU RTX 3050)

Метод: прогон OWLv2 (Apache-2.0) по **каждому кадру всех 40 роликов** с батареей текстовых описаний (полный кадр + вырезка стола);
признак видео = максимум медианы окна 3 кадров. Правило берём, только если пропущенное нарушение **выше максимума всех 19 норм** с запасом.

| Нарушение | Признак | Результат | Решение |

| X-4, X-38 деньги прошлого клиента | «a stack of banknotes» на столе в 3 кадрах прихода следующего клиента | 0.20–0.29 vs нормы ≤ 0.10 | ✅ `cash_exposed` |
| X-46 напиток | «a coffee cup» на столе, замер раз в 2 с | 0.40 vs нормы ≤ 0.11 | ✅ `food_drink` (+ полный кадр, если стол не найден — ловит и на «другом ракурсе») |
| X-40 личные вещи | «a coat lying on a table» | высоко, пока пальто **надето** (с 1 с), на столе — как у норм | ❌ ложные на клиентах в куртках |
